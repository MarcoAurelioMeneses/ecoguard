# API reference

The contract is the OpenAPI document generated by springdoc from the controllers. With the API running:

- `GET /openapi.json` — the document
- `GET /docs` — the rendered reference
- `GET /health` — liveness
- `GET /` — pointers to those paths

This foundation does not serve districts, scores, or the analyst. Those paths will be added to the same application and will appear in the same document. Do not keep a hand-written copy of the schema that can drift. A client should be generated from `/openapi.json` when a screen needs it.

Security on every response: `X-Content-Type-Options`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, a locked-down `Permissions-Policy`, and `Content-Security-Policy: default-src 'none'`. `GET /` is rate limited. `GET /health` and the documentation paths are not, so a platform probe is not throttled.

Run it from the repository root:

```bash
./backend/gradlew -p backend :api:bootRun
```

The document is generated by springdoc. `POST /analyst/questions` is part of the same document. It returns 503 until `OPENAI_API_KEY` is set.
